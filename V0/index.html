Projects

Automated Sports Team Performance Forecasting

Undergraduate Dissertation · University of Aberdeen · 2024–2025

Purpose

This project investigated the prediction of English Premier League match outcomes using historical match data. It explored how engineered features, ensemble models, and temporal modelling could be combined in a forecasting workflow.

My Contribution

For my undergraduate dissertation, I developed a machine learning workflow covering data preparation, feature engineering, model development, and application integration.

I worked with multi-season Premier League data and constructed features including rolling performance statistics, Elo ratings, and historical team information.

I designed a two-stage hybrid framework combining tree-based models, including XGBoost, LightGBM, and Random Forest, with an LSTM meta-learner to model temporal patterns.

I also built a Flask web application that allows users to enter match information and view model-generated predictions through an interactive interface.

Project details

Key Components

  • Historical match data cleaning and preparation
  • Rolling statistics and Elo-based feature engineering
  • Tree-based ensemble models and LSTM modelling
  • A Flask interface connecting user input with model predictions

Technologies: Python · PyTorch · scikit-learn · pandas · XGBoost · LightGBM · Flask · HTML/CSS

Fruit Quality Detection and Automatic Vending System

University-Level Innovation Training Project · November 2022–June 2024

Role: Core Team Member — Algorithm and Software Development

Purpose

This team project explored the integration of fruit recognition and quality assessment into an automated vending system. It combined computer vision, an interactive software interface, and camera and sensor integration.

The recognition component focused on identifying fruit types and distinguishing fresh from decayed fruit.

My Contribution

As a core team member responsible for algorithms and software, I worked on image preprocessing, recognition model development, and the integration of the detection workflow with the application.

I developed a PyQt interface and worked on connecting cameras and sensors with the software backend.

I also led dataset annotation work involving more than 5,000 fruit images and approximately 15,000 bounding boxes, supporting the preparation of data for model development.

Project details

Key Components

  • Fruit-type recognition and freshness classification
  • Image preprocessing and training-data preparation
  • Dataset annotation and bounding-box labelling
  • A PyQt graphical interface
  • Integration between software, cameras, and sensors

Project Recognition

The project was selected as a university-level innovation training project. The team also obtained software copyright registration in China.

Technologies: Python · Deep Learning · Image Processing · Object Detection · PyQt

Thompson Sampling for Recommendation

Machine Learning Experimentation Project

Purpose

This project explored how multi-armed bandit methods can support recommendation decisions by balancing exploration and exploitation: trying less-understood options while using knowledge gained from existing feedback.

The work involved MovieLens 1M and e-commerce interaction data, with a focus on Thompson Sampling and the design of reward signals.

My Contribution

I worked on Python implementations of Thompson Sampling, including the use of Beta distributions to represent uncertainty and update action selection based on feedback.

I explored how different e-commerce actions, such as viewing, favouriting, adding to a cart, and purchasing, could be translated into weighted reward signals.

I also worked on experimental code and visualisations for examining algorithm behaviour, including comparisons with Explore-Then-Commit and analysis using cumulative reward and regret.

Project details

Key Components

  • Thompson Sampling implementation and feedback-based updates
  • Preparation of movie-rating and e-commerce interaction data
  • Reward design using different types of user behaviour
  • Experimental comparison of exploration–exploitation strategies
  • Visualisation and interpretation of dataset-based results

What I Learned

This project strengthened my understanding of uncertainty-aware decision-making and the influence of reward definitions on experimental outcomes. It also highlighted the need to distinguish results obtained from historical datasets or simulations from improvements demonstrated in a live recommendation system.

Technologies: Python · NumPy · pandas · Matplotlib · Thompson Sampling · Multi-Armed Bandits

Selected Publication

Adaptive Recommendation System Strategies: An Exploration of Online Machine Learning Algorithms

First Author · 2024

Published in the Proceedings of the 1st International Conference on Engineering Management, Information Technology and Intelligence (EMITI 2024).

This paper explores adaptive recommendation strategies through reinforcement learning and multi-armed bandit frameworks. It examines the exploration–exploitation trade-off and discusses approaches including Epsilon-greedy, Upper Confidence Bound, and Thompson Sampling.

The work considers applications across recommendation settings such as e-commerce, news, and online advertising.

Topics: Reinforcement Learning · Multi-Armed Bandits · Recommendation Systems · Online Learning
