# Fenglin Lu: Personal Website

A static single-page site made of `index.html`, `style.css`, `script.js` and `assets/`.

## Open locally

Double-click `index.html`, or serve this folder with any static file server.

## Host as static files

Upload the folder with its structure intact to any static host. All paths are relative, so it also works from a sub-folder on GitHub Pages.
